# Nina Carducci
<h3>📖 Description:</h3>

- A photographer portfolio website, with a high SEO score, optimized for performance and accessible to everyone.

<h3>🚀 Demo:</h3>

- [Live Preview](https://prayeronaiwunina-carducci-website.vercel.app/)

<h3>🛠️ Technologies:</h3>

- `HTML5`
- `CSS3`
- `JavaScript (ES6+)`
- `WAVE Tool`
- `Chrome DevTools`


<h3>💻 Functionalities:</h3>

- Interactive UI elements
- Semantic HTML
- High SEO score
- High color contrast for better accessibility

<h3>⚙️ Installation:</h3>

To run this project locally, you can follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/prayer-on/nina-carducci-website.git 
```

2. Select the Project folder:
```bash
cd nina-carducci-website
```

3. Install the dependencies:
```bash
npm install
```

4. Start the server:
```bash
npm start
```
